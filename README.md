## 🚀 Getting Started

### Prerequisites

* Node.js (v16 or higher)
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/PranavDDabade/PortfolioPranav.git
cd PortfolioPranav
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm start
```
